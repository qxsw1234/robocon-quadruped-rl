# 四足机器人强化学习训练原理说明

> 本文件对应考核要求第 6 条「了解训练原理」，结合本项目使用的 **legged_gym + rsl_rl + Isaac Gym** 框架和 Unitree A1 机器人，从算法、状态/动作空间、奖励设计、域随机化、训练流程五个层面进行说明。

---

## 1. 总体框架

本项目采用"**强化学习 + GPU 并行仿真**"的标准训练范式：

```
Isaac Gym (GPU 物理仿真器，4096 个并行环境)
        │  每个环境一个 A1 机器人，独立地形、命令、噪声
        ▼
legged_gym (环境封装：观测/动作/奖励/地形课程)
        │
        ▼
rsl_rl (PPO 算法库：Actor-Critic 网络、策略更新)
        │
        ▼
TensorBoard 训练曲线 → 收敛后导出策略 → 仿真回放演示
```

- **Isaac Gym**：NVIDIA 的 GPU 加速物理仿真器（PhysX 物理引擎），一次性在 GPU 上并行模拟 4096 个机器人，每个机器人有独立的地形、随机命令、噪声和扰动。这是四足 RL 训练速度的关键——单环境串行仿真需要数周，GPU 并行把训练压缩到几十分钟。
- **legged_gym**：ETH RSL 实验室开源的腿式机器人 RL 环境库，定义了观测空间、动作空间、奖励函数、地形生成和课程学习逻辑。
- **rsl_rl**：轻量级 PPO 实现，包含 Actor-Critic 网络、经验存储、PPO 更新逻辑。

## 2. 强化学习基本概念（以本项目为例）

强化学习的目标：让智能体（A1 机器人）通过试错，学会最大化**累计奖励**的策略。

| 概念 | 本项目中的含义 |
|---|---|
| 智能体 (Agent) | A1 机器人的控制策略（神经网络） |
| 环境 (Environment) | Isaac Gym 中的仿真世界（地形、物理、命令） |
| 状态/观测 (State/Observation) | 机器人传感器读数，如身体姿态、关节角度等 |
| 动作 (Action) | 12 个关节的目标位置增量 |
| 奖励 (Reward) | 每步返回的标量信号，指导机器人"该做什么" |
| 策略 (Policy) | 神经网络：观测 → 动作的映射，即训练产物 |

**马尔可夫决策过程 (MDP)**：每一步，智能体观测到状态 $s_t$，输出动作 $a_t$，环境转移并返回奖励 $r_t$。策略训练即寻找 $\pi(a_t|s_t)$ 使得期望累计奖励 $\mathbb{E}[\sum_t \gamma^t r_t]$ 最大。

## 3. 算法：PPO（Proximal Policy Optimization，近端策略优化）

本项目使用的算法是 **PPO**，一种**策略梯度 (Policy Gradient)** 类算法：

1. **Actor-Critic 结构**：
   - **Actor（策略网络）**：输出动作分布（高斯分布，均值 + 标准差），输入观测。结构为 3 层 MLP：512→256→128，激活函数 ELU。
   - **Critic（价值网络）**：估计状态价值 $V(s)$（期望累计奖励），用于减小策略梯度方差。同结构 MLP。
2. **GAE（广义优势估计）**：用 Critic 估计的 $V(s)$ 计算优势函数 $A_t$，平衡偏差与方差（$\lambda=0.95$，$\gamma=0.99$）。
3. **重要性采样与 clip 限制**：PPO 用旧策略采样的数据多次更新新策略，为避免一次更新过大导致训练崩溃，对策略比率 $r = \pi_{new}/\pi_{old}$ 进行裁剪（clip 参数 0.2），限制每次更新幅度。
4. **更新流程**：每轮迭代用当前策略采集 24 步 × 4096 环境 = 98,304 条经验 → 计算优势 → 对 Actor/Critic 做 5 轮（epoch）小批量（4 个 mini-batch）梯度更新，学习率 1e-3（自适应 KL 调度）。
5. **熵正则化**：entropy_coef=0.01，鼓励探索，防止策略过早收敛到局部最优。

训练目标是混合损失：
```
L = L_policy_clip - c1 * L_value + c2 * H(π)
```

## 4. 观测空间与动作空间（A1 机器人）

### 机器人：Unitree A1
- **12 自由度**：4 条腿 × 3 关节（hip 横滚 / thigh 髋关节 / calf 膝关节）
- 控制方式：**PD 位置控制**。策略输出的是目标关节位置的增量：
  `target_angle = action_scale × action + default_angle`（action_scale=0.25，PD 刚度 20 N·m/rad，阻尼 0.5）
- 仿真步长 5ms，策略每 4 个仿真步（20ms）执行一次（decimation=4）

### 观测空间（235 维，含特权观测）
| 部分 | 维度 | 内容 |
|---|---|---|
| 线速度 | 3 | 机体坐标系下 x/y/z 速度 |
| 角速度 | 3 | 机体角速度 |
| 重力向量 | 3 | 姿态信息（roll/pitch） |
| 关节位置/速度 | 24 | 12 关节 ×（位置、速度） |
| 上一次动作 | 12 | 动作平滑性 |
| 命令 | 3 | 目标线速度 vx/vy、偏航角速度 |
| 高度测量 | 187 | 地形高度采样（粗糙地形感知） |
| 额外 | — | 时延/噪声等 |

### 动作空间（12 维）
连续动作，每个关节的目标位置偏移，范围被 clip（clip_actions=100）。

## 5. 奖励设计（核心！）

奖励函数是"行为目标"的编码。legged_gym 的奖励是**每步各项加权求和**：

```
r_total = Σ scale_i × reward_i
```

各奖励项含义（本项目基线配置）：

| 奖励项 | 权重 | 含义与动机 |
|---|---|---|
| tracking_lin_vel | +1.0 | **速度跟踪**：指数形式 $\exp(-\text{error}^2/\sigma)$，误差越小越接近 1。奖励机器人跟随命令速度——走起来的核心 |
| tracking_ang_vel | +0.5 | 偏航角速度跟踪，控制转向 |
| lin_vel_z | -2.0 | 惩罚机体垂直速度（身体上下颠簸 = 不稳定） |
| ang_vel_xy | -0.05 | 惩罚俯仰/横滚角速度（姿态抖动） |
| torques | -0.0002 | 惩罚关节力矩（A1 基线配置，省力并保护电机） |
| dof_acc | -2.5e-7 | 惩罚关节加速度（动作平滑） |
| feet_air_time | +1.0 | 奖励脚离地时间（鼓励抬脚迈步，形成步态） |
| collision | -1.0 | 惩罚大腿/小腿撞击地面（防止磕碰） |
| action_rate | -0.01 | 惩罚动作变化率（平滑控制） |
| dof_pos_limits | -10.0 | 惩罚关节超出软限位（保护机械结构） |

**关键设计思想**：
1. **速度跟踪用指数函数**：`r = exp(-error²/σ)`（σ=0.25），误差 0 时奖励=1，误差越大奖励指数衰减——比线性误差更平滑、梯度更好。
2. **稀疏 vs 密集奖励**：本项目全部使用密集奖励（每步都有信号），引导性强，训练快。
3. **正负平衡**：`only_positive_rewards=True`，总奖励为负时裁剪为 0，避免早期"原地罚站"的局部最优。
4. **奖励项之间相互博弈**：torques 惩罚想要"省力"，tracking_lin_vel 想要"走得快"，feet_air_time 想要"迈开腿"——策略在约束下寻找平衡，这就是"奖励塑形"。

**修改奖励 = 修改行为**（考核要求 5 的实验基础）：
- 把 tracking_lin_vel 权重调 0 → 机器人没有"前进"目标 → 不走路；
- 去掉 feet_air_time → 没有抬脚压力 → 步态拖地、僵化；
- 增大 torques 惩罚 → 更省力但动作幅度变小、速度下降。
（本项目通过三组对照实验验证，见《奖励实验分析》）

## 6. 域随机化与课程学习（让策略"真实可用"）

- **地形课程 (Terrain Curriculum)**：训练从平缓地形开始，机器人表现好（episode 长）就升到更陡的地形（斜坡、台阶），表现差就降级。让策略逐步学会复杂地形。
- **域随机化 (Domain Randomization)**：
  - 摩擦系数随机 0.5~1.25
  - 随机外力推搡（15s 一次，最高 1 m/s）
  - 传感器噪声（关节位置、速度、IMU）
  - 目的：让策略对真实世界的不确定性鲁棒，减小 sim-to-real 差距。
- **观测噪声**：训练时加入噪声，使策略不依赖精确传感器值。

## 7. 训练流程（本项目实际执行）

```
1. 初始化 4096 个 A1 环境（随机地形、随机命令）
2. 循环迭代（每轮）：
   a. 用当前策略采集 24 步经验（4096×24 = 98,304 步）
   b. 计算优势 A_t（GAE）
   c. PPO 更新 Actor/Critic（5 epoch × 4 mini-batch）
   d. 每 50 轮保存 checkpoint，TensorBoard 记录奖励曲线
3. 1500 轮后收敛，导出策略
4. 回放演示：加载 checkpoint → 下发固定命令（0 或 1.0 m/s）→ 记录视频
```

**训练指标解读**（TensorBoard 曲线）：
- `train/total_reward`：总奖励趋势，上升并收敛说明学会任务
- `train/mean_reward_tracking_lin_vel`：速度跟踪奖励——**是否学会走路的核心指标**
- `train/mean_episode_length`：平均 episode 长度，接近上限 1000 步（20s）说明不摔倒了
- `train/terrain_level`：地形难度等级，上升说明适应能力增强

**本项目训练数据**：
- 训练步数：1500 迭代 × 24 步 × 4096 环境 = **147,456,000 环境步**（约 1.47 亿步）
- 训练时间：约 42 分钟（RTX 4060 Laptop，4096 并行环境，吞吐 ~61k steps/s）

## 8. 为什么这能学会"站立"和"直线行走"？

- **站立**：当命令速度为 0 时，速度跟踪奖励要求实际速度≈0——机器人学到最优策略是保持静止、维持平衡（身体高度稳定、姿态水平），这是"稳定站立"。
- **直线行走**：当命令 vx=1.0, vy=0, yaw=0 时，策略输出周期性关节动作（对角小跑步态 trot），产生前进速度并跟踪目标。因为训练中命令在 [-1,1] 随机采样，策略学会了"任意给定速度都能跟"，1.0 m/s 是训练分布内的常见值。
