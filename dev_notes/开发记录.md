### 关键技术调研结论
| 问题 | 结论 |
|---|---|
| Isaac Gym Preview 4 是否支持 RTX 40 系（sm_89）？ | 支持（PhysX 内核编到 SM_80，40 系靠二进制向前兼容运行） |
| 官方 README 的 torch 1.10+cu113 能用吗？ | **不能**，40 系上报 nvrtc 错误，必须换 torch 2.3.x+cu121 |
| Python 版本？ | Isaac Gym 二进制只支持 Python ≤3.8 ABI → 必须用 python 3.8 |
| 驱动 570+/580 兼容性？ | 有 Vulkan/coredump 报告 → 用 `--headless` 规避；不行则切 mjlab |
| 8GB 显存 | `--num_envs` 降到 1024~2048（默认 4096 需 ~12GB） |

### 环境搭建报错记录（供报告用）
1. **torch 官方源极慢**（6分钟 56KB）→ 改用阿里云镜像 `https://mirrors.aliyun.com/pytorch-wheels/cu121/`，秒速下载
2. **rsl_rl 主分支是 5.4.2 新版**（API 与 legged_gym 不兼容、要求 python≥3.9）→ `git checkout v1.0.2` 旧版
3. **rsl_rl 安装卡住** → 因 pip 尝试从 PyPI 下载 torchvision（网络慢）→ `--no-deps --no-build-isolation`
4. **libpython3.8.so.1.0 找不到** → Isaac Gym 二进制需要 libpython → `export LD_LIBRARY_PATH=$CONDA_PREFIX/lib`（已固化到 `scripts/leg_env.sh`）

### 性能基准（RTX 4060 Laptop, 8GB）
| num_envs | 显存 | 迭代时间 | 吞吐 |
|---|---|---|---|
| 512 | ~1.6GB | 0.41s | 30k steps/s |
| 2048 | 3.9GB | 0.84s | 56k steps/s |
| 4096 | 4.6GB | 1.67s | 61k steps/s |
- 4096 envs × 1500 迭代（默认配置）约需 **42 分钟**，完全可行
